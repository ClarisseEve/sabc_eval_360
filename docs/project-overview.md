# Project Overview

SABC Eval360 est une plateforme d’évaluation 360° organisée autour de deux applications principales:

- `apps/web`: frontend React SPA
- `apps/api`: backend NestJS

## Stack active

- Frontend: React 19, TypeScript, Vite, React Query
- Backend: NestJS 11, Prisma 6, Passport JWT
- Données core: MySQL
- Données métier: PostgreSQL

## Capacités principales

- dashboards par rôle
- workflows d’évaluation
- administration structure / rôles / utilisateurs / remplacements
- analytics et notifications

## État architectural

Le dépôt ne s’appuie plus sur Laravel/Inertia ni sur les anciens services Go dans sa chaîne active.
