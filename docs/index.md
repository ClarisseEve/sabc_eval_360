## Project Overview

SABC Eval360 is a 360-degree evaluation platform with role-based dashboards, evaluation workflows, and analytics. It combines a Laravel/Inertia UI with Go microservices and ETL pipelines.

## Project Structure

This project consists of 4 parts:

### Application principale (app)
- **Type:** web
- **Location:** `.`
- **Tech Stack:** Laravel 12, Inertia, React 19, Vite 6
- **Entry Point:** `public/index.php`

### Service Analytics (analytics)
- **Type:** backend
- **Location:** `services/analytics`
- **Tech Stack:** Go 1.23, Gin, ClickHouse
- **Entry Point:** `services/analytics/cmd/server/main.go`

### Service Evaluation (evaluation)
- **Type:** backend
- **Location:** `services/evaluation`
- **Tech Stack:** Go 1.23, Gin, PostgreSQL, Redis
- **Entry Point:** `services/evaluation/cmd/server/main.go`

### Data Pipelines (pipelines)
- **Type:** data
- **Location:** `data_pipelines`
- **Tech Stack:** Python, pandas, sqlalchemy
- **Entry Point:** `data_pipelines/main_pipeline.py`

## Getting Started

### App Setup

```bash
cp .env.example .env
composer install
pnpm install
php artisan key:generate
composer dev
```

### Services

```bash
# Analytics
cd services/analytics
 go run ./cmd/server

# Evaluation
cd services/evaluation
 go run ./cmd/server
```

### Pipelines

```bash
cd data_pipelines
python main_pipeline.py
```
